# Closed-Loop Discovery of H Spillover-Driven CO2 Reduction in Acidic Electrolyte by Phosphine-Modified Cu

**Code provider:** Yuming Su  
**Research Focus:** Machine learning-driven discovery of phosphine-modified copper catalysts for CO2 electroreduction

## Project Overview

This repository contains the computational codes and experimental data for the closed-loop discovery of hydrogen spillover-driven CO2 reduction catalysts. The project employs machine learning techniques, specifically XGBoost regression with SHAP analysis, to identify optimal phosphine-modified copper catalysts for electrochemical CO2 reduction in acidic electrolytes.

# Machine learning for phosphine modified copper catalysts

**Regression and molecular mapping code:** Yuming Su

Please use **[ML_reproducibility_clean_20261027.zip](./ML_reproducibility_clean_20261027.zip)** to reproduce the regression, candidate prediction, SHAP analysis, and molecular mapping workflows associated with the manuscript. The package contains aligned CSV inputs, updated Python scripts, pinned dependencies, and detailed usage instructions. Results are generated by running the scripts; no precomputed prediction files are required.

## Download and run

Download and extract the ZIP, then open PowerShell in the extracted directory containing `run_regression.py`. The package was tested with **Python 3.8.8 on Windows x64**.

```powershell
py -3.8 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_regression.py --jobs 2
.venv\Scripts\python plot_regression.py
```

If `py -3.8` is unavailable, replace it with the path to a Python 3.8 x64 executable. The regression command runs the 93-, 108-, and 127-molecule stages, fitting 160 models per configuration and 1,760 models in total. Predictions, evaluation metrics, and SHAP results are saved in `outputs/replay/`; figures are saved in `outputs/regression_figures/`.

To generate the molecular map, run:

```powershell
.venv\Scripts\python run_molecular_map.py
```

Map coordinates and figures are written to `outputs/molecular_map/`. Input files are not overwritten. For repeated runs, choose a new output directory as described in the README inside the ZIP.

## Data and interpretation

The package includes experimental targets, numerical descriptors, molecule identities, and saved holdout memberships for the following stages:

| Stage | Measured molecules | Available descriptor columns | Unmeasured candidates |
| --- | ---: | ---: | ---: |
| First round | 93 | 45 | 2,459 |
| Second round | 108 | 54 | 172 |
| Final regression | 127 | 54 | None |

The first-round candidate input has been deduplicated. Unmeasured candidates do not require placeholder target values. The molecular map uses a separate 2,475-entry dataset. All regression targets and predictions are expressed in percentage points. The historical selected-feature combinations and model parameters are specified in `settings.py`.

Candidate predictions are the mean of 160 models, consistent with the historical Table S6 procedure documented in our contemporaneous records. The saved holdout memberships and historical selected-feature combinations are retained. The model seed is fixed to 0 for repeatable execution. Complete historical training-row orders were not retained, so exact agreement with every published prediction is not guaranteed. The manuscript and supplementary tables remain the record of the original results; regenerated outputs are reproduction runs.

Validation uses repeated random holdouts. Development data are used for early stopping and feature selection, while prospective experimental performance is reported separately. The optional `select_features.py` script performs a new seeded feature search, which may select different features from the historical combinations used by the main regression script. See the packaged README for detailed settings and stage-specific commands.

### Decision Tree Analysis (`Desicion Tree/`)

**Focus:** Classification analysis using decision tree algorithms for catalyst performance prediction

#### Key Files:
- **`feature_comparison.ipynb`** - Jupyter notebook for decision tree-based feature comparison and classification analysis
- **`tree_features0103.csv`** - Feature matrix used for decision tree training
- **`target_cla.csv`** - Binary classification targets (0/1) for 127 molecules, indicating high/low performance catalysts

**Purpose:** This analysis complements the regression models by providing a classification perspective, identifying clear decision boundaries for catalyst performance and offering interpretable rules for catalyst selection.

### Molecular Mapping (`Molecular map/`)

**Focus:** Comprehensive molecular database and fingerprint analysis for phosphine ligands

#### Key Files:
- **`P_MAP241018.ipynb`** - Jupyter notebook for molecular mapping and fingerprint analysis
- **`P_test_0625.csv`** - Comprehensive database of 127 phosphine molecules with CAS numbers, Chinese/English names, and SMILES structures
- **`Pfp_20241018.csv`** - Molecular fingerprint data for computational analysis

**Purpose:** This section provides the foundational molecular database used throughout the study, including:
- Complete molecular identification (CAS numbers, systematic names)
- SMILES representations for computational processing
- Molecular fingerprints for similarity analysis and structure-activity relationships

**Database Content:** The molecular database includes diverse phosphine ligands ranging from simple trialkylphosphines to complex chiral bisphosphines, covering:
- Trialkyl/triaryl phosphines (e.g., triphenylphosphine, tricyclohexylphosphine)
- Bidentate phosphines (e.g., dppe, dppp, dppb derivatives)
- Chiral phosphines for asymmetric catalysis
- Phosphine oxides and related compounds
- Specialized ligands with unique electronic/steric properties
